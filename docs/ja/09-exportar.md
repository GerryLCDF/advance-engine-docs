##9.1。統合統合（PLAY / STOP）

##9.2。 ROMをエクスポートする

**EXPORT** ボタンをクリックすると、出力アクションを含むメニューが開きます。

- **プロジェクトを保存:** 現在の状態が維持されます。
- **GBA ROM のエクスポート:** はプロジェクトを実行を保存し、** 可能性のある ROM** (`.gba` ファイル) をコンパイルして生成し、プロジェクトのビルドを自動的に開きます。
- **曲 / スプライト / 背景 / スクリプトのエクスポート:** 個々のアセットを抽出します(ソースアセットが必要な場合に役立ちます)。
- **プロジェクト計画を開きます:**エクスプローラーでプロジェクトのルート設定を開きます。エクスプローラーでROMは、任意のG BA任意で実行したり、**フラッシュカート**にダンプして実際のコンソールでテストできます。

##9.4。GBA プラットフォームの制限GBA はソフトウェアによって描画します**VB LANK** 、68 ライン×1232 サイクル)。作業がその時間をかけてと、アプリケーションはフレームが早くなり、アニメーションの速度が低下します。

### 予算ルール
制限はアクターの固定数ではありません。**カメラが認識できるスプライトピクセルの数**です。
```
~83.800 ciclos ÷ ~15 ciclos por píxel ≈ ~5.600 px de sprite en cámara por frame
```
|スプライトの組み合わせ |よろしいですか？
| :--- | :--- |
| 21×31ピクセル（各651ピクセル）のアクター 5～6人用 |快適 |
| 64×64ピクセル (4096ピクセル) のアクター 1人 + 16×16ピクセルの 2人 |良い |
| 16×16ピクセル (各256ピクセル) の ~21人のアクター |限界まで |
|

### 俳優がカメラから離れている
- **カメラ外のアクターは VBLANK** をほとんど消費しません。
- **部分的に画面外**の俳優は、目に見える部分の料金のみをお支払いいただきます。
- **必要な数のアクター**をシーンに配置できます。その瞬間にフレームが焦点を合わせているものだけがカウントされます。

### その他の制限
- **メモリ:** は制限ではありません。アクターの背景 (`gActorBack`) は EWRAM (~76.8 KB) で 240x160 で、スプライト フレームは ROM にあり、アクターのリストは小さいです。
- **トランジション:** 30×20 タイル × 8 フレーム × スピード 5 のタイルセットトランジションは、約 24,000 の vsync およそ 6 ～ 7 分に相当します。インスペクタで速度を調整して短くします。
